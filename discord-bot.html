Opportunity-Tracking AI Bot

Independent Passion Project  •  Discord + AI

Application Tracker AI
2026–present
Personal Project Discord Bot AI · RAG

A Discord bot that tracks application deadlines for programs, scholarships, competitions, and internships — and answers questions about them using an AI assistant. It uses retrieval-augmented generation (RAG) over a local SQLite database, so it never invents a fact, deadline, or link.

Cost
$0 Software Cost
  • Discord bots are free to run.
  • AI answers are powered by Groq — free tier, no credit card required.
  • Whether hosting is also free depends on where the bot runs — a free-tier host keeps it at $0/month, while a dedicated server would cost more.
What's Behind It

Seeded from a 2026–2027 Student Opportunity Tracker spreadsheet — 86 curated programs across Medical/Healthcare, Tech/STEM, Business/Entrepreneurship, Humanities/Law/Politics, and Leadership/Civic, each with eligibility requirements, deadlines, and priority already filled in.

Built to Be Honest, Not Flashy

There is deliberately no automated Open/Closed status indicator (no colored circle). Earlier versions tried keyword-based scraping to detect this automatically, but it wasn't reliable enough across dozens of different program websites to show students a status light they could trust. Instead, the bot shows the real Applications Open / Deadline dates on file and lets the student judge for themselves — more honest than a guess.

Two Ways to Use It
Quick Q&A
@ApplicationTracker AI

Ask a question and get a grounded, structured "Executive Advisor" briefing back — an executive summary, program cards, and a strategic recommendation.

Full Roadmap
/roadmap

A full phased "User Journey" career-planning roadmap for a specific grade level, interest area, and start timeline — grouping tracked programs into timeline phases with cost, format, and recommendation-letter details, only stated when the database actually confirms them (otherwise it says "verify on the official page" rather than guessing).
